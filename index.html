发布 / 分享给家长（加密隔离）

点击下面的按钮，系统会把每位学生的成绩单独加密，生成两份内容：

  1. grades-data.js：加密后的数据文件。请上传到你的 GitHub 仓库根目录（覆盖同名文件并重新发布）。
  2. 家长访问码清单：每位学生一个唯一访问码，请私发给对应家长（微信/短信均可）。

家长打开同一个网址 parent.html，输入访问码即可只看到自己孩子的成绩；其他孩子的数据在文件中是密文，看不到。访问码等同于查看钥匙，请通过私密渠道发送、勿公开。
